**L'enunciat és a [ENUNCIAT.md](ENUNCIAT.md).** Llegeix-lo aquí, en línia.

Aquest repositori conté les plantilles de resposta de l'examen: `test.md` (el test), `teoria.md` (les preguntes de teoria D1 i D2) i el CSV de dades `dades_trimestral_1bat-prog.csv`.

## Com el fas servir
1. Entra a `test.md` i a `teoria.md` i copia'n el contingut (botó **Raw**, i copia-ho tot).
2. Al **repositori que has creat per a l'examen**, fes **Add file → Create new file** per a cada un, amb el mateix nom, i enganxa-hi el contingut.
3. Omple la columna **Resposta** del test amb la lletra de cada pregunta i escriu les respostes de teoria sota cada títol. Fes **Commit changes**.
4. Lliura a Classroom l'enllaç del teu repositori (i el del teu full de càlcul).
