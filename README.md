# Plantilla de l'examen trimestral · 1BAT Programació i robòtica

Aquest repositori només conté el fitxer `test.md`, on has de respondre el test de l'examen.

## Com el fas servir
1. Entra a `test.md` i copia'n el contingut (botó **Raw**, i copia-ho tot).
2. Al **repositori que has creat per a l'examen**, fes **Add file → Create new file**, anomena'l `test.md` i enganxa-hi el contingut.
3. Omple la columna **Resposta** amb la lletra de cada pregunta i fes **Commit changes**.
4. Lliura a Classroom l'enllaç del teu repositori (i el del teu full de càlcul).
